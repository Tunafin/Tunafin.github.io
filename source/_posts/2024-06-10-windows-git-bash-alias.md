每次要在終端機開啟 AI 編程助手或 IDE 時，總是要敲長長的指令嗎？
本篇文章將手把手教你如何在 Windows 的 **Git Bash** 環境中，將長指令 `antigravity-ide .` 縮寫成超好記的 `agy .`，讓開發流程更流暢！

## 為什麼要設定別名（Alias）？

* **省時省力**：減少重複輸入長指令的時間。
* **降低出錯率**：避免因為拼錯單字而導致指令執行失敗。

---

## 實作步驟

Git Bash 在每次啟動時，都會自動讀取使用者目錄下的設定檔。我們只要把縮寫寫進 `.bashrc` 檔案中即可。

### 第一步：開啟 Git Bash

請在電腦中開啟你的 **Git Bash** 終端機。

### 第二步：使用編輯器開啟設定檔

在終端機中輸入以下指令，這會透過內建的 `vim` 編輯器建立或開啟 `.bashrc` 檔案：

```bash
vim ~/.bashrc
```

### 第三步：寫入別名指令

進入 `vim` 編輯器後，請依照下列步驟操作：

1. 按下鍵盤上的 **`i`** 鍵，進入**輸入模式**（此時視窗左下方會出現 `-- INSERT --` 字樣）。
2. 在檔案中貼上或輸入以下指令：

```bash
alias agy="antigravity-ide"
```

3. 按下鍵盤左上角的 **`Esc`** 鍵，退出輸入模式。
4. 輸入 **`:wq`**（代表儲存並離開），然後按下 **`Enter`** 鍵。

### 第四步：讓設定立即生效

檔案儲存後別急著重啟終端機！直接輸入以下指令，就能讓剛剛的設定立刻生效：

```bash
source ~/.bashrc
```

---

## 驗證成果

現在，切換到你任何一個專案的資料夾目錄，然後輸入：

```bash
agy .
```

如果成功喚起 `antigravity-ide` 並載入當前目錄，就代表設定成功囉！
